復習

プログラミング言語でいう関数は

  1. 処理の一部を分割するためのものと
  2. 入力値から出力値を計算するためのもの（数学でいう関数）

の2種類に分けて考えるとよい。

教科書 p. 78 の marine は 1 のタイプの例である。 以下も処理を分割するための関数の形である．実行せよ． 

#!/usr/bin/perl -w
use strict;

sub f1{
    print "Hello f1\n";
}

sub f2{
    print "Hello f2\n";
}

&f1;
&f2;
&f1;

教科書 p.83 の関数 max は 入力値から出力値を計算するタイプの例である． 以下もそのタイプの簡単な例である．実行せよ． 

#!/usr/bin/perl -w
use strict;

my $out;

sub f3{
    my($x) = @_;

    return $x;
}

$out = &f3(1);
print "$out\n";
$out = &f3(2);
print "$out\n";
$out = &f3(3);
print "$out\n";

上記の関数 f3 は入力値をそのまま出力する関数である．
