maximum value of binary tree
二分木の最大値

ミニレポート第 8 回課題

二分木の合計 を参考に， 引数が指す節を根とする二分木のラベルの最大値を 求める関数 my_max を作成せよ．

プログラムの仕様

  • 前提：節のラベルは正の整数値であるとする．
  • 引数：節を指すポインタ
  • 戻り値：引数の指す節を根とする木のラベルの中で 最大のものの値を返す．ただし， 木が空のときは 0 を返すものとする．

関数定義の書き出し例: int my_max(struct node *p)

プログラム全体についての注意

  • ファイル名は report08.c とする
  • 二分木の合計 にある 節の定義，postorder 関数, sum 関数はそのまま残し， main の上に my_max 関数を作ることで作成せよ． main 関数を書き換えて十分テストを行え． 提出時の report08.c の main 関数内はどんなものでもよい．
