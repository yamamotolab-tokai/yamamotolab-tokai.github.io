ミニレポート第 2 回課題

第1回課題で作成した 教科書List 2.2 を完成させたプログラムに 関数 print_all を追加する．（report01.c を report02.c という名前でコピーし， report02.c のほうに書き加える） 関数 print_all 仕様は以下の通りとする．

print_allの仕様

  • 前提：教科書List2.2の table 配列に要素が格納されており， 要素の個数はグローバル変数 n に格納されている．
  • 引数と戻り値は無い．関数定義の書き出しは
    void print_all(void)
    となる．
  • 出力：画面に 配列 table の全要素（0番からn-1番）の添字， メンバ key, data の値を添字の順に出力する． 例えば配列 table が以下の内容であり，グローバル変数 n の値が 10 であるとき，
    keyの値dataの値
    table[0]11
    table[1]32
    table[2]43
    table[3]84
    table[4]145
    table[5]146
    table[6]187
    table[7]208
    table[8]219
    table[9]2510
    以下のように出力される． 
    0:key=1,data=1
1:key=3,data=2
2:key=4,data=3
3:key=8,data=4
4:key=14,data=5
5:key=14,data=6
6:key=18,data=7
7:key=20,data=8
8:key=21,data=9
9:key=25,data=10

    図r2.1 print_all の出力例1

    また，配列 table が以下の内容であり，グローバル変数 n の値が 3 であるとき，
    keyの値dataの値
    table[0]11
    table[1]32
    table[2]43
    以下のように出力される． 
    0:key=1,data=1
1:key=3,data=2
2:key=4,data=3

    図r2.2 print_all の出力例2

    出力フォーマットも上記出力例に合わせたものにせよ． グローバル変数 n の値が 0 のときは何も出力してはいけないことに 注意せよ．

プログラム全体についての注意

  • ファイル名は report02.c とする
  • プログラム全体としては第1回課題 で作成した教科書List 2.2 を完成させたものをベースにして それに print_all を追加したもを作成せよ． 教科書List2.2 にある部分には手を加えず，(binary_search 関数や 構造体の定義を変更してはいけない） 教科書List2.2 に書かれている部分の 後に関数 print_all を挿入せよ．
  • main 関数を適当に何度か書き換えて動作させ， print_all が正しく動作していることを確認せよ． 提出時の report02.c の main 関数内はどんなものでもよい．
